# Restaurant Menu

A modern and responsive restaurant menu web application built with Next.js, React, Tailwind CSS, and Supabase.

The application allows customers to explore the restaurant's menu, browse food categories, view item details and prices, and access general restaurant information.

## Features

- Browse the restaurant menu
- Browse menu items by category
- View item names, descriptions, prices, and images
- Restaurant information and opening hours
- Responsive design for desktop, tablet, and mobile
- RTL support for Persian content
- Dynamic data powered by Supabase
- Image storage using Supabase Storage

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Supabase
- JavaScript
